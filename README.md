# MuZero with Self-Supervised Auxiliary Losses

This project extends the **MuZero** implementation by [Werner Duvaud](https://github.com/werner-duvaud/muzero-general) by introducing two self-supervised auxiliary losses to improve the quality of the latent representations learned by the model:

- **Reconstruction loss** ($l^g$): forces the network to reconstruct the original observation from the latent state, via an additional decoder network.
- **Consistency loss** ($l^c$): enforces coherence between the latent states predicted by the dynamics function and those directly encoded by the representation function.

The goal is to evaluate whether these auxiliary losses speed up learning or improve the final performance of MuZero on low-dimensional environments (CartPole-v1, LunarLander-v2, MountainCar-v0).

## Installation

**Requirements:** Python 3.10+, CUDA optional.

```bash
git clone https://github.com/<your-username>/muzero-ssl.git
cd muzero-ssl
pip install -r requirements.txt
```

For LunarLander, the Box2D backend is required:

```bash
pip install "gymnasium[box2d]"
```

## Usage

### Interactive Training

```bash
cd src
python muzero.py
```

A menu will be displayed to select the game and mode (train, test, etc.).

You can also start training directly from the command line:

```bash
python muzero.py cartpole
```

### Automated Benchmark

To reproduce the experiments described in the project, run the predefined benchmarks:

```bash
# CartPole-v1
python src/benchmark_cartpole.py

# LunarLander-v2
python src/benchmark_lunarlander.py
```

Each benchmark runs the following 5 experiments over multiple seeds:

| ID | Configuration | $l^g$ | $l^c$ | Pre-training |
|----|---------------|:-----:|:-----:|:------------:|
| 1  | Baseline (standard MuZero) | ✗ | ✗ | ✗ |
| 2  | Reconstruction | ✓ | ✗ | ✗ |
| 3  | Consistency | ✗ | ✓ | ✗ |
| 4  | Hybrid | ✓ | ✓ | ✗ |
| 5  | Hybrid + Pre-training | ✓ | ✓ | ✓ |

Results are saved in `results/<game>/<experiment>/seed_<n>/`.

### Plot Generation

```bash
cd src
python plot.py
```

Plots are saved in `plots/cartpole/`. The script also prints mean reward and standard deviation statistics for each experiment over the final training window.

## Configuration

Each game has a `MuZeroConfig` class in its respective file under `games/`. The main parameters related to the self-supervised extensions are:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `reconstruction_loss_weight` | Weight of the reconstruction loss ($l^g$) | `0` |
| `consistency_loss_weight` | Weight of the consistency loss ($l^c$) | `0` |
| `self_supervised_steps` | Self-supervised pre-training steps before RL | `0` |

To override the configuration at runtime:

```python
from muzero import MuZero
import games.cartpole

config = games.cartpole.MuZeroConfig()
config.reconstruction_loss_weight = 1
config.consistency_loss_weight = 1
config.self_supervised_steps = 5000

mz = MuZero("cartpole", config)
mz.train()
```

## Technical Details

### Architecture

The fully connected network has been extended with a **reconstruction network** (`ReconstructionNetwork`) that decodes the original observation from the latent state produced by either the representation or dynamics function. The reconstruction loss is computed as the MSE between the reconstruction and the target observation.

The **consistency loss** is computed as the MSE between the latent state produced by the dynamics function at step $t$ and the one produced by the representation function applied directly to the real observation at step $t$, with the target detached from the computational graph.

### Overall Loss Function

During standard training:

$$\mathcal{L} = \mathcal{L}_{value} + \mathcal{L}_{reward} + \mathcal{L}_{policy} + \lambda_g \cdot l^g + \lambda_c \cdot l^c$$

During self-supervised pre-training (`self_supervised_steps > 0`), **only** $l^g$ and $l^c$ are used, with no reward or value signal from the environment.
